# Shega Events

Shega Events plans and produces live experiences, including concerts, festivals,
and brand activations. Based in Addis Ababa, the team supports events from the
first idea through the final moment.

This website introduces Shega Events, highlights selected events and photographs,
and gives visitors a visual archive of past experiences. People planning an event
can use the contact form to prepare an inquiry with their event details and send
it by email.
